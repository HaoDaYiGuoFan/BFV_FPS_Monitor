BFV FPS Monitor
WPF 监控面板 · 部署与使用

战地 5 实时性能面板：帧率 / 1% Low / CPU·GPU 温度与占用 / 显存 / 内存 / 网络速率。 基于 PresentMon 进程外帧捕获 与 LibreHardwareMonitor 传感器读取，不注入游戏进程，规避 EAC 风险。

架构总览 SEC 01 / ARCHITECTURE

数据只有一条正向流：两个独立采集源 → 引擎汇聚 → UI 与 CSV 双出口。帧路径（PresentMon 子进程 stdout）与硬件路径（WMI/传感器轮询）互不阻塞，任一源失败只降级显示 N/A，不影响另一路。

面板内容 SEC 02 / UI

深色单窗布局，参考游戏加加的信息分区：顶部状态徽章，中部三张主卡（GPU / CPU / FPS），下部帧率统计与网络速率。

区域指标来源与说明
顶栏徽章游戏状态 / PresentMon 状态绿点 = 运行中并显示 PID；灰点 = 待机。每秒随进程轮询刷新
GPU 卡核心温度 大字，≥85°C 红 / ≥70°C 橙LibreHardwareMonitor GPU 传感器（NVIDIA / AMD / Intel）；占用条超 92% 变红。温度或占用读不到时显示 N/A，不影响其他项
GPU 占用 进度条 + 百分比
显存 已用 / 总量，>90% 红
温度告警色阶
CPU 卡包温度 Package / CCD1 优先温度/频率取自 CPU 传感器；占用取自 Windows PerformanceCounter（比 WMI 更稳）；内存用量在传感器缺失时由 GlobalMemoryStatusEx 兜底
CPU 占用 进度条 + 百分比
内存 已用 / 总量 GB
FPS 卡瞬时 FPS / 帧时间 / 窗口帧数PresentMon 帧数据；无游戏时显示 --
帧率统计平均 FPS / 1% Low / 0.1% Low滑动窗口 1000 帧：1% Low 取最差 1% 帧的平均帧速度，反映卡顿；运行状态区有当前阶段的中文提示
运行状态文字

快速开始 SEC 03 / QUICKSTART

推荐直接使用已发布的单文件包（publish 目录 / zip 包），无需安装 .NET。

  1. 取得程序文件

    发布包共两个文件，必须放在同一目录：BFV_FPS_Monitor.exe（129.7MB 单文件，内嵌 .NET 10 运行时）+ PresentMon.exe（388KB 帧捕获器）。

  2. 右键 → 以管理员身份运行

    读取 CPU/GPU 温度传感器与 PresentMon ETW 捕获都需要管理员权限。程序内置 manifest 要求提权，正常双击会自动弹 UAC，确认即可。

  3. 启动战地 5

    面板顶部徽章 1 秒内变绿（显示 PID），PresentMon 自动启动并开始捕获，无需任何手动操作。

  4. 查看数据 / 退出

    游戏退出后面板自动回到待机态，PresentMon 子进程被同步终止，不留残留。关窗即退出，CSV 自动落盘。

注意：PresentMon.exe 必须与主程序同目录。缺失时程序仍能运行，硬件/网络面板正常，但帧率区始终为 --。

从源码编译 SEC 04 / BUILD

需要 .NET 10 SDK（本机已装 10.0.401）。项目根目录即 E:\PrivateProjects\Private\BFV_FPS_Monitor。

# Debug 编译（输出 bin\Debug\net10.0-windows\）
dotnet build BFV_FPS_Monitor.csproj -c Debug

# Release 单文件发布（输出 publish\）
dotnet publish BFV_FPS_Monitor.csproj -c Release -r win-x64 --self-contained true ^
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true ^
  -o publish

# PresentMon.exe 不会打进单文件包，手动补一份到 publish 目录
copy PresentMon.exe publish\

MainWindow.xaml / .csWPF 深色面板：三主卡 + 统计 + 网络，DispatcherTimer 150ms 读快照刷新，温度/占用色阶告警

数据文件 SEC 05 / CSV

日志固定写在 exe 目录\bfv_fps_log.csv，首帧到达后按帧追加，AutoFlush 保证断电尽量留存，Excel / WPS 可直接打开做曲线。

列含义
Timestamp本帧写入时刻（yyyy-MM-dd HH:mm:ss.fff）
FrameTimeMs / FPS本帧帧耗时与瞬时帧率
AvgFps / OnePercentLow / ZeroPointOnePercentLow当前滑动窗口统计值
GpuTemp / GpuLoad / GpuMemUsed / CpuLoad写入时刻的硬件快照；传感器缺失时写 N/A

排错清单 SEC 06 / TROUBLESHOOT

现象排查
帧率区一直 --① 确认同目录有 PresentMon.exe；② 游戏切 D3D12 渲染模式（设置 → 图形 → 渲染后端）；③ 以管理员运行主程序；④ PresentMon 须为 1.10.0+，旧版对 D3D12 支持不完整
温度全 N/A必须管理员权限运行；部分主板/驱动不开放个别传感器，属正常降级，其余指标不受影响
双击闪退UAC 弹窗被取消会直接退出；重试并在弹窗选「是」
网络速率异常偏大统计含虚拟网卡（VPN/虚拟机/局域网传输）；属设计行为——面板反映的是整机全部 IPv4 流量
CSV 无新增行无帧数据时 CSV 也不写入（按帧追加）；先解决帧捕获问题
PresentMon 残留进程正常情况下游戏退出/关窗都会 Kill 子进程；若强杀主程序（任务管理器结束进程）可能残留，手动结束 PresentMon.exe 即可

安全边界 SEC 07 / SAFETY

本工具不注入、不挂接、不读取游戏内存：PresentMon 通过 Windows ETW（Event Tracing）在进程外观察呈现事件，LibreHardwareMonitor 走内核驱动读取传感器，网络速率来自系统网卡统计——三者均为系统级公开机制，与作弊工具实现路径完全不同，不触碰 Easy Anti-Cheat 的检测红线。

唯一要求的管理员权限用于传感器读取与 ETW 订阅，程序无网络通信、无自启动、无后台驻留，关窗即完全退出。
